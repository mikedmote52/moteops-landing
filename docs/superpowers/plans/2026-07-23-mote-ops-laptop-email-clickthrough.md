# Mote Ops Laptop Email Clickthrough Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the confusing monitor cut with a readable inbox, Mote Ops email, CTA click, and `moteops.tech` load on the actor's real laptop in the original office.

**Architecture:** Capture four screen-only HTML/CSS plates, key the accepted green laptop footage, and place the plates behind the keyed foreground using tracked perspective geometry. Build the laptop discovery as a focused intermediate clip, then assemble it with the existing cleanup montage, controlled actor outcome, and complete beach ending in the deterministic FFmpeg pipeline.

**Tech Stack:** Static HTML/CSS, Bash, headless Chrome, FFmpeg/ffprobe, Node.js test runner, Node.js media-ledger updater, Playwright with system Chrome, Vercel protected preview.

## Global Constraints

- Spend no generation credits and generate no replacement actor footage.
- Preserve the original room, actor, desk, papers, phone, laptop bezel, and scene lighting.
- Show the inbox, opened email, CTA click, and `moteops.tech` load inside the green-screen laptop.
- Use the exact subject `AI could help your business. Where do you start?`
- Use the exact preview/body `Mote Ops finds the work AI can take off your plate.`
- Use the exact CTA `See how Mote Ops can help`.
- Give the opened email at least 2.2 seconds of stable reading time.
- Show the CTA click response for at least 0.35 seconds.
- Show the `moteops.tech` landing state for at least 1.2 seconds.
- Preserve each cleanup interface for 1.8 seconds.
- Preserve the controlled actor outcome and complete eight-second beach ending.
- Keep the film silent, 24fps, H.264, fast-start, and approximately 28 seconds.
- Preserve the current contained desktop and mobile player, Motion control, play-once behavior, replay behavior, poster fallback, reduced-motion behavior, and written disclosure.
- Do not merge, publish to `moteops.tech`, alter access settings, or change production.
