## What this branch adds

- `pipeline.html` — single-page mobile-first dashboard, vanilla JS, no
  build step. Reads `data/dashboard_state.json` on load. Sections (top
  to bottom, mobile-first scroll order):
  1. **Today's queue** — hero number, next-call card with prep status, expandable brief panel.
  2. **Pipeline metrics** — total in flight, new 7d, advanced 7d, win rate.
  3. **Active customers** — one card per customer, color-coded by stage signal (green/amber/red), stage pill, named pain quote, meta tags, next-action panel with owner tag.
  4. **Pending your review** — staged proposals/follow-ups/declines awaiting Mike's hands.
  5. **System health** — Calendly webhook freshness, intake reasoning log, prep-check launcher, operator signals, Anthropic API cap window.
  6. **Recent activity** — flat timeline of last 20 events.
  7. **Operator signal map** — link out to the full pain-theme/vertical report; this card is a summary, not a duplicate.
- `data/dashboard_state.json` — first generation of the JSON contract,
  populated from current customer state (Marcus Chen, Sarah Jensen,
  Rosa Gutierrez).
- `.claude/launch.json` — local dev server config so Claude Code can
  preview the dashboard without pushing to GitHub Pages.

## Visual language

Matches `sidegigbot.html` — dark theme (`#08080d` bg, `#0c0e14` cards,
`#10b981` green, `#f59e0b` amber, `#ef4444` red), Inter font, 12px card
border-radius, 1px hairline borders, no decorative gradients except on
the hero card. Mobile-first: designed at 375px wide, stat grid widens
to 4 columns at 640px, health grid widens to 2 columns at 880px. Tap
targets ≥ 44px on the brief toggle and signal-map link.

No bullet lists in body content. Numerics in tabular-nums. Banned phrases
absent (verified against the brand-brief list).

## Data refresh

The `data/dashboard_state.json` file is regenerated by a launchd job
that lives in the mote-ops repo:

- Script: `mote-ops/tools/dashboard_state_builder.py`
- Plist: `mote-ops/launchd/com.moteops.dashboard-refresh.plist`
- Cadence: every 5 minutes, RunAtLoad true
- Atomic write (`os.replace`) so the dashboard never reads a half-written file.

Install command in `mote-ops/launchd/README.md`. Not auto-installed.
